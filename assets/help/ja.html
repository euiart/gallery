はじめての方ははじめにだけ読めば十分です。ほかは必要なときに開いてください。

はじめに
  1. 上の作品・配置タブで作品を選び、写真を押して画像をアップロードします。
  2. タイトル、制作年、素材、横・縦のサイズ(cm)を入力します。入力したサイズで壁に掛かります。
  3. 展示室の画面で作品をドラッグして位置を決めます。
  4. 空間・照明タブで展示室の雰囲気を選びます。
  5. 下の保存するを押します。保存した内容だけが観覧者に表示されます。

保存するまでは、変更は自分の画面にだけ表示されます。保存すると、いま観覧している人の画面にもすぐ反映されます。

展示情報
  • 展示タイトル、会期、作家紹介、作家ノートを入力します。入口の画面と壁の文字に使われます。
  • 英語・日本語の欄を入力すると、観覧者が言語を切り替えたときにその文章が表示されます。空欄の場合は韓国語が表示されます。
  • 展示のリンクをコピー、展示のQRコード:展示のアドレスをコピーしたり、QR画像(PNG)として保存できます。はがきやポスターに使えます。
作品の追加と修正
  • + 作品を追加で新しい作品を作ります。一覧で作品を押すと編集欄が開きます。
  • 写真を押すか、ファイルをドラッグして置くと画像が変わります。大きな写真は自動で縮小されます。
  • アップロードに失敗すると、その作品に警告ともう一度アップロードボタンが表示されます。アップロード前に保存すると、観覧者には前の画像が表示されます。
  • 複数の作品をまとめて修正:制作年と素材を、すべての作品または空欄の作品だけにまとめて入力します。
  • 順番のボタンで鑑賞の順番を変えます。削除は2回押すと実行されます。
作品の配置
  • 作品・配置タブが開いているとき、展示室の作品をドラッグすると移動します。
  • ドラッグ中、目の高さ(中心1.5m)、壁の中央、隣の作品の中心に近づくとぴたりと合い、赤い線が出ます。Shiftを押しながらドラッグすると自由に動かせます。
  • 位置の欄で壁を変えたり、数値で正確に合わせることができます。5cmずつ動かすボタン、壁の中央へ、目の高さのボタンもあります。
  • リセットのボタンで、その作品またはすべての作品を自動配置に戻します。
  • ほかの作品と重なると警告が出ます。
セット(二連・三連)
  • 一覧の右にあるリンクボタンを押すと、すぐ上の作品とセットになります。もう一度押すと解除されます。
  • セットにする作品は、先に順番を隣同士にしておいてください。
  • セットは一緒に動き、キャプションは1つになります。セットのタイトルと作品の間隔も決められます。
  • このセットを解除はそのセットだけ、セットをすべて解除はすべてのセットを解除します。解除した作品は今の位置のままです。
  • グリッドに入っている作品はセットにできません。
グリッド配置
  • 壁にグリッドで配置を開き、壁、行と列の数、間隔を決めて、マスごとに作品を選びます。
  • グリッドは壁の中央に自動で合わせられます。照明は縦の列ごとに1つ付きます。
  • キャプションは、作品ごと、グリッド全体に1つ、なしから選びます。
  • グリッドの中の作品を直接ドラッグすると、その作品だけグリッドから外れます。
キャプション・額縁・照明
  • キャプションの位置は右・左・下・上から選びます。作品ごとに非表示にもできます。
  • 額縁はキャンバス、浮かし額、額縁、掛け軸、アンティークから選びます。展示全体の初期値を決め、作品ごとに変えられます。
  • 作品ごとに照明の強さと形も変えられます。
空間・照明
  • 空間テーマ、床、壁、天井、椅子を選びます。展示室の幅・奥行き・天井の高さも変えられます。
  • 空間の明るさと作品の照明は別々に調整します。キャプションは照明に合わせて明るくなったり暗くなったりします。
  • 水の庭では、空間の明るさが昼・夕暮れ・夜を兼ねます。
  • 観覧者の影の効果をオンにして、影の種類(人物、人物+猫、猫、恐竜)を選びます。
  • 編集が遅いときは、一番下の編集中は床の映り込みを消すをオンにしてください。この端末にだけ適用され、観覧者の画面はそのままです。
音楽
  • 音楽ファイルをアップロード:MP3・M4A・OGG・WAV(20MB以下)。
  • 曲名、音量、入場時に自動再生するかどうかを決めます。
  • 使用する権利のある音楽だけをアップロードしてください。
プリセット
  • 今の作品配置と展示室のサイズに名前を付けて保存し、あとで読み込むで戻せます。
  • いくつかの配置を試すときに使います。プリセットも保存するを押すと残ります。
リンクとQRコード
  • 展示情報タブのボタンは、展示全体へのアドレスです。
  • この作品のリンクをコピー、この作品のQRコードは、その作品の前から鑑賞を始めるアドレスです。実際の会場のキャプションの横に貼るのに便利です。
  • 新しく追加した作品は、保存した後にリンクが使えます。
  • QRコードを印刷するときは一辺を2cmより大きくし、まわりの白い余白を切らないでください。
保存・元に戻す・プレビュー
  • 保存する:観覧者に反映されます。
  • ↶ ↷:1段階ずつ元に戻す、またはやり直します。保存した後でも戻せます。
  • 最後の保存に戻す:保存していない変更をすべて取り消します。
  • 観覧者の画面で見る:編集欄を閉じて実際の見え方を確認します。上の編集を押すと戻ります。
  • 設定ファイルを書き出す:展示の設定をファイルとして保存します。バックアップ用です。
ショートカット
Ctrl + S保存
Ctrl + Z元に戻す
Ctrl + Shift + Zやり直す
Shift + ドラッグ吸着せずに自由に動かす
W A S D / 矢印キー歩く(Shiftを押すと速く)
Esc開いている画面を閉じる

MacではCtrlの代わりにCmdを押します。

困ったときは
  • 変更が観覧者に表示されない:保存するを押したか確認してください。
  • 画面が古いまま:ページを再読み込みしてください。MacはCmd + Shift + R、WindowsはCtrl + F5です。
  • 画像がアップロードできない:インターネット接続を確認し、もう一度アップロードを押してください。
  • 編集が遅い:空間・照明タブの編集中は床の映り込みを消すをオンにしてください。
  • 間違えて変更した:Ctrl + Zで戻すか、最後の保存に戻すを押してください。
