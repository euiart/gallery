はじめての方ははじめにだけ読めば十分です。ほかは必要なときに開いてください。

はじめに
  1. 上の作品・配置タブで作品を選び、写真を押して画像をアップロードします。
  2. タイトル、制作年、素材、横・縦のサイズ(cm)を入力します。入力したサイズで壁に掛かります。
  3. 展示室の画面で作品をドラッグして位置を決めます。
  4. 空間・照明タブで展示室の雰囲気を選びます。
  5. 下の保存するを押します。保存した内容だけが観覧者に表示されます。

保存するまでは、変更は自分の画面にだけ表示されます。保存すると、いま観覧している人の画面にもすぐ反映されます。

展示情報
  • 展示タイトル、会期、作家紹介、作家ノートを入力します。入口の画面と壁の文字に使われます。
  • 英語・日本語の欄を入力すると、観覧者が言語を切り替えたときにその文章が表示されます。空欄の場合は韓国語が表示されます。
  • 展示のリンクをコピー、展示のQRコード:展示のアドレスをコピーしたり、QR画像(PNG)として保存できます。はがきやポスターに使えます。
作品の追加と修正
  • + 作品を追加で新しい作品を作ります。一覧で作品を押すと編集欄が開きます。
  • 写真を押すか、ファイルをドラッグして置くと画像が変わります。大きな写真は自動で縮小されます。
  • アップロードに失敗すると、その作品に警告ともう一度アップロードボタンが表示されます。アップロード前に保存すると、観覧者には前の画像が表示されます。
  • 写真をまとめてアップロード:写真を複数選ぶと、1枚ごとに作品が1つ作られます。タイトルはファイル名、高さは写真の比率で入ります。一度に20枚までです。
  • 複数の作品をまとめて修正:制作年と素材を、すべての作品または空欄の作品だけにまとめて入力します。
  • 順番のボタンで鑑賞の順番を変えます。削除は2回押すと実行されます。
作品の配置
  • 作品・配置タブが開いているとき、展示室の作品をドラッグすると移動します。
  • ドラッグ中、目の高さ(中心1.5m)、壁の中央、隣の作品の中心に近づくとぴたりと合い、赤い線が出ます。Shiftを押しながらドラッグすると自由に動かせます。
  • 位置の欄で壁を変えたり、数値で正確に合わせることができます。5cmずつ動かすボタン、壁の中央へ、目の高さのボタンもあります。
  • リセットのボタンで、その作品またはすべての作品を自動配置に戻します。
  • ほかの作品と重なると警告が出ます。
セット(二連・三連)
  • 一覧の右にあるリンクボタンを押すと、すぐ上の作品とセットになります。もう一度押すと解除されます。
  • セットにする作品は、先に順番を隣同士にしておいてください。
  • セットは一緒に動き、キャプションは1つになります。セットのタイトルと作品の間隔も決められます。
  • このセットを解除はそのセットだけ、セットをすべて解除はすべてのセットを解除します。解除した作品は今の位置のままです。
  • グリッドに入っている作品はセットにできません。
グリッド配置
  • 壁にグリッドで配置を開き、壁、行と列の数、間隔を決めて、マスごとに作品を選びます。
  • グリッドは壁の中央に自動で合わせられます。照明は縦の列ごとに1つ付きます。
  • キャプションは、作品ごと、グリッド全体に1つ、なしから選びます。
  • グリッドの中の作品を直接ドラッグすると、その作品だけグリッドから外れます。
キャプション・額縁・照明
  • キャプションの位置は右・左・下・上から選びます。作品ごとに非表示にもできます。
  • 額縁はキャンバス、浮かし額、額縁、掛け軸、アンティークから選びます。展示全体の初期値を決め、作品ごとに変えられます。
  • 作品ごとに照明の強さと形も変えられます。
空間・照明
  • 空間テーマ、床、壁、天井、椅子を選びます。展示室の幅・奥行き・天井の高さも変えられます。
  • テーマは15種類です。ヘリンボーンのギャラリー、ライムストーンのホール、ダークラウンジなど写真素材のテーマ10種類は、壁・床・天井が合うように組まれています。テーマを選ぶと壁・床・天井がセットで変わり、そのあと一つずつ変えられます。レール・照明の色(白・黒)も選べます。写真素材は Poly Haven(CC0)のテクスチャです。
  • 空間の明るさと作品の照明は別々に調整します。キャプションは照明に合わせて明るくなったり暗くなったりします。
  • 水の庭では、空間の明るさが昼・夕暮れ・夜を兼ねます。
  • 観覧者の影の効果をオンにして、影の種類(人物、人物+猫、猫、恐竜)を選びます。
  • 編集が遅いときは、一番下の編集中は床の映り込みを消すをオンにしてください。この端末にだけ適用され、観覧者の画面はそのままです。
音楽
  • 音楽ファイルをアップロード:MP3・M4A・OGG・WAV(20MB以下)。
  • 曲名、音量、入場時に自動再生するかどうかを決めます。
  • 使用する権利のある音楽だけをアップロードしてください。
プリセット
  • 今の作品配置と展示室のサイズに名前を付けて保存し、あとで読み込むで戻せます。
  • いくつかの配置を試すときに使います。プリセットも保存するを押すと残ります。
リンクとQRコード
  • 展示情報タブのボタンは、展示全体へのアドレスです。
  • この作品のリンクをコピー、この作品のQRコードは、その作品の前から鑑賞を始めるアドレスです。実際の会場のキャプションの横に貼るのに便利です。
  • 新しく追加した作品は、保存した後にリンクが使えます。
  • QRコードを印刷するときは一辺を2cmより大きくし、まわりの白い余白を切らないでください。
保存・元に戻す・プレビュー
  • 保存する:観覧者に反映されます。
  • ↶ ↷:1段階ずつ元に戻す、またはやり直します。保存した後でも戻せます。
  • 最後の保存に戻す:保存していない変更をすべて取り消します。
  • 観覧者の画面で見る:編集欄を閉じて実際の見え方を確認します。上の編集を押すと戻ります。
  • 設定ファイルを書き出す:展示の設定をファイルとして保存します。バックアップ用です。
  • 保存せずに画面を閉じた場合、同じ端末で次に編集を開くと続きから作業するか確認されます。
  • ほかの端末で先に保存された内容があるとお知らせします。保存するをもう一度押すと自分の画面の内容で上書きし、最後の保存に戻すを押すと相手の内容を読み込みます。
自動鑑賞
  • 上の作品一覧を開いて自動鑑賞を押すと、ボタンが消えて作品を順番にゆっくり表示します。
  • 画面録画で展示の動画を作るときや、会場のモニターで流すときに使います。
  • 画面を押すかキーを押すと終わります。
  • 展示のアドレスの最後に?auto=1を付けると、入場してすぐ自動鑑賞が始まります。
ショートカット
Ctrl + S保存
Ctrl + Z元に戻す
Ctrl + Shift + Zやり直す
Shift + ドラッグ吸着せずに自由に動かす
W A S D / 矢印キー歩く(Shiftを押すと速く)
Esc開いている画面を閉じる

MacではCtrlの代わりにCmdを押します。

複数の作品をまとめて動かす

作品タブの一覧で、作品写真の左上にある四角をタップして複数選びます。一覧の上に黒い帯が出ます。

  • 目の高さにそろえる: 選んだ作品の中心を床から1.5mの高さにそろえます。
  • 最初の作品の高さにそろえる: 選んだ中で一覧のいちばん上にある作品の高さにそろえます。
  • 間隔を均等に: 同じ壁で3点以上選ぶと、両端の作品はそのままに、あいだの間隔を等しくします。
  • 矢印 5cm: 選んだ作品をいっしょに5cmずつ動かします。

セットはひとまとまりで動き、グリッドに入っている作品は動きません。間違えたら Ctrl + Z で元に戻せます。

スマートフォンで歩く

スマートフォンとタブレットでは、右下に丸いスティックが出ます。上下に倒すと前後に歩き、左右に倒すと向きを変えます。画面をドラッグして見回す、床や作品をタップして移動する操作はそのままです。

展示を隠す・複製する

展示情報タブの展示一覧に表示しないをオンにして保存すると、展示一覧には出ず、アドレスやQRコードを知っている人だけが見られます。準備中の展示に使ってください。

この展示を複製して新しい展示を作るは管理者アカウントにだけ表示されます。新しいアドレスを入れて作ると、今の展示の空間・照明・音楽をそのまま持つ新しい展示が非表示の状態でできます。今の展示は変わりません。準備ができたら、新しい展示で非表示をオフにして保存してください。

ほかの人に新しい展示を編集してもらうには、IDもいっしょに入れます。その人のログインアカウントは、SupabaseのAuthenticationで別に作る必要があります。

来場記録

展示情報タブの来場記録を開くと、今日・直近7日・直近30日・合計の入場回数が出ます。来場者が入場ボタンを押したときに1回数え、編集のためにログインした人は数えません。誰が来たかは記録しません。

最初に一度だけ、SupabaseのSQL Editorに supabase-setup.sql の「7) 방문 기록」の部分を貼り付けて実行してください。実行するまでは数字が出ないだけで、展示はそのまま動きます。

芳名録

来場者は画面上の芳名録ボタンから、お名前と短い書き込み(300文字まで)を残せます。書き込みはすぐには表示されず、作家が編集画面の芳名録タブで公開するを押すと来場者に表示されます。

  • 確認待ちの書き込みがあると、編集画面を開いたときにお知らせし、タブに赤い数字が付きます。
  • 公開した書き込みも非表示にするや削除でいつでも下げられます。削除は2回押すと実行されます。
  • 公開・非表示・削除は保存しなくてもすぐ反映されます。
  • 芳名録が不要な展示は、芳名録タブでこの展示で芳名録を受け付けるをオフにして保存してください。
  • いたずらを防ぐため、インターネットのアドレス(リンク)を含む書き込み、同じ書き込みの繰り返し、1分以内の再書き込み、短時間に集中する書き込みは受け付けません。
  • 来場者のメールアドレスや連絡先は受け取りません(お名前と書き込み、時刻のみ)。

最初に一度だけ、SupabaseのSQL Editorに supabase-setup.sql の「8) 방명록」の部分を貼り付けて実行してください。実行するまでは芳名録ボタンが出ないだけで、展示はそのまま動きます。

Web図録

画面上の図録ボタンで、本のように1枚ずつめくる図録が開きます。パソコンでは見開き、スマートフォンでは1ページずつ表示されます。矢印・キーボード・スワイプでめくり、PDFで保存を押すと印刷画面からPDFとして保存できます。

  • 自動図録:展示の情報から自動で作られます(表紙・タイトル・作家ノート・作品ごとに1ページ・作家紹介・奥付)。編集画面の図録タブで表紙の作品、序文、奥付の文を決められます。
  • 図録の画像:作った図録のページ画像を複数まとめて選ぶと、ファイル名の順に入ります。印刷用PDFをそのまま選んでも、ページごとに画像にしてアップロードします。順番の入れ替えや削除も同じタブで行います。
  • 最初のページ(表紙)だけ1枚、残りは見開きで表示されます。画像がすでに見開きならこの設定をオフにしてください。
  • 来場者のPDF保存を止めるには来場者がPDFで保存できるようにするをオフにします。元のPDFもアップロードしておくと、来場者がその元ファイルをダウンロードできます。
  • 図録のリンクをコピーで、図録がすぐ開くアドレスを作れます。

アップロードした画像や変えた設定は、保存を押すと来場者に反映されます。

バックアップと復元

無料サーバー(Supabase)は自動でバックアップを取りません。展示情報タブのバックアップと復元で、ときどき保存しておきましょう。

  • この展示の設定を保存:この展示の設定が展示アドレス.jsonとして保存されます。下のバーの設定ファイルを書き出すと同じです。
  • 設定ファイルを読み込む:保存したファイル(または全体バックアップ)の内容にこの展示を戻します。「保存」を押すと反映され、↶ で取り消せます。
  • すべての展示をまとめて保存(管理者):すべての展示の設定・芳名録・来場記録を一つのファイルに保存します。画像と音楽は含まれません。
  • サーバー容量を確認(管理者):アップロードした画像・音楽が無料枠1GBのうちどれだけかを表示します。来場者への転送量はSupabaseの使用量ページで確認します。
  • 無料サーバーは1週間以上使われないと一時停止することがあります。GitHubのリポジトリが3日ごとにアクセスして防いでいますが、もし止まったらSupabaseのダッシュボードでプロジェクトを再開してください。停止中はGitHubのexhibitionsフォルダの展示ファイルで展示が開きます。古い内容のこともあるので、大きく直した後は保存した展示アドレス.jsonを同じ名前でそのフォルダに上げておくと安心です。
困ったときは
  • 変更が観覧者に表示されない:保存するを押したか確認してください。
  • 画面が古いまま:ページを再読み込みしてください。MacはCmd + Shift + R、WindowsはCtrl + F5です。
  • 画像がアップロードできない:インターネット接続を確認し、もう一度アップロードを押してください。
  • 編集が遅い:空間・照明タブの編集中は床の映り込みを消すをオンにしてください。
  • 間違えて変更した:Ctrl + Zで戻すか、最後の保存に戻すを押してください。
