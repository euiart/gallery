euiart 온라인 갤러리 자동 백업 (매주 월요일 새벽, GitHub Actions)

latest.json  가장 최근 백업
weekly/      주마다 하나씩, 최근 26개
status.json  마지막으로 확인한 날(편집 화면이 읽어요)

되살리기: 편집 화면 → 전시 정보 → 백업과 복원 → [자동 백업에서 이 전시 불러오기]
  또는 이 파일을 내려받아 [설정 파일 불러오기]로 고른 뒤 저장하기.
들어 있는 것: 모든 전시의 설정, 공개된 방명록 글, 서버에 올린 파일 목록(파일 자체는 아님).
들어 있지 않은 것: 확인 전 방명록 글, 방문 기록(로그인해야 읽을 수 있어서), 이미지·음악 파일.
